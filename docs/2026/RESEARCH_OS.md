# The Research OS commit this programme runs on

This repository records which Research OS it was driven by. Nothing of Research
OS is vendored here — no code, no schema, no configuration. This file and the
`.research/` capsule (which is the Research Capsule *specification*, not
Research OS's implementation) are the whole relationship.

```text
Research OS repository   /home/nicacevedo/research/research-os
branch                   rc/thesis-pilot
base                     integration/autonomous-runtime-vnext @ b6109c1
capsule specification    Research Capsule v1, capsule_version 1, schema_version 1
```

The exact commit is recorded per experiment in each preregistration record, not
here, because a commit named once in a README is a commit that stops being true.
